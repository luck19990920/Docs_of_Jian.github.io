# 本网站的前生今世

## 起源

&emsp;&emsp;萌生做一个属于自己网站的想法始于2020年。那时正处于新冠疫情大爆发时期。我每天的活动只局限在我的卧室里。天天无聊透了！在这样的情况之下，我在某一天偶然看到了b站中一个播放量超高的前端入门教程。回想起之前一直对网站是怎么做出来充满疑问，我抱着试试看的态度听了几节课。没想到课程对于我这个非计算机专业的人来说还挺通俗易懂的，于是在漫长的假期中我断断续续地把HTML和CSS的相关内容都听完了，并且完成了课程中的一些案例。

## 发展
&emsp;&emsp;真正开始着手写网站是在2024年，也就是研二那一年。作为课题组中主要负责理论计算方面的学生，我常常面临着需要指导课题组中其他学生上手简单理论计算的情况。我发现课题组中不同的人理论计算学习初期遇到的问题都是差不多的，因此我萌生了想写一个组内理论计算SOP的想法。当时，组内已有word版的理论计算SOP，但是这样的SOP都属于每一个个人，不同的人手上拿的SOP不尽相同。为了提高处理问题的效率，我把目光转向了网页版的SOP。这样做我认为有两个好处。第一个好处就是课题组中的人能够随时随地打开SOP，第二个好处就是我希望更多的人能够来完善这个SOP(后面我发现使用git工具能够很好地实现这一点。但是后面由于各种各样的原因，最终本网站中的内容还是由我自己一个人在维护)。


&emsp;&emsp;当时刚开始准备写网站时，作为一个非科班的我真的不知道如何下手。之前学过的课程只告诉了我如何进行网页排版，如何在网页上实现想要的效果，但是并没有教我如何把自己写好的网页传到互联网上去。就这样，我被卡住了几个星期。后面的某一个星期，当我正在网上检索计算化学的一个问题时，我偶然进入了[厦门大学程俊老师课题组组内wiki](https://wiki.cheng-group.net/)。然后，我深深地被网页中专业的解释所惊讶。在页面的底端，我发现了Made with Material for MkDocs几个小字，随后我好奇地点了进去。就这样，我进了MkDocs的坑。由于当时的我还比较熟悉Python，所以一个星期之后我就上传了我的第一个网页。

## 未来
&emsp;&emsp;目前，我已经研究生毕业，并且进入了一个全新的领域中。因此，本网站后续将不再更新计算化学相关的内容。之前更新的计算化学相关内容将在本网站中永久保留。后续本网站中更新的内容将会聚焦在电子、计算机与非虚构类书籍等方面。
